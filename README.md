# 📁 Python File Organizer

A Python utility that automatically organizes files into folders based on their extensions.

## ✨ Features

- Automatically categorizes files by extension.
- Supports images, documents, videos, audio, archives, and code files.
- Creates destination folders automatically.
- Handles unknown file types using an `Others` folder.
- Avoids overwriting files with duplicate names.
- Includes basic error handling.
- Uses Python's standard library.

## 🛠️ Technologies Used

- Python 3
- pathlib
- shutil

## 🚀 Getting Started

### Prerequisites

Install Python 3 from:

https://www.python.org/downloads/

### Installation

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/python-file-organizer.git
```

Navigate to the project directory:

```bash
cd python-file-organizer
```

Run the application:

```bash
python main.py
```

## 📖 How to Use

1. Run the program.
2. Enter the path of the folder you want to organize.
3. Confirm the operation.
4. The program moves files into category folders.
